# Notes for Claude

## Notion team hub
The team's documentation lives in Notion, page **Perkly** (https://app.notion.com/p/2c68db61692380baa9b2ea00e3f94156).
Keep it in step with the work: whenever something changes that the team would need to know, update the matching Notion page in the same session.

| Change | Notion page |
| --- | --- |
| New or changed portal feature (admin / operations / finance / AM) | How-to: Perkly team portal |
| New or changed merchant portal feature | How-to: Merchant portal |
| New or changed app feature | How-to: Student app |
| Who can see or approve something | Roles & approvals |
| Launch checklist item added or done (`docs/LAUNCH_CHECKLIST.md`) | Launch checklist |
| Testing steps, tester messages, test shop | Testing |
| Store texts or graphics (`docs/STORE_LISTING.md`) | App store listings |
| Domains, DNS, email providers | Domain & email setup |
| Links, demo accounts, tools | Links & logins |
| Code layout, builds, deploys | Tech overview (for developers) |

Rules:
- Never put secret keys (service role, API keys, tokens) in Notion. Demo account logins are allowed (Links & logins).
- Old planning pages live in "Archive (old docs)"; don't edit or delete them unless asked.
- Write for non-technical teammates: short steps, real button names.
